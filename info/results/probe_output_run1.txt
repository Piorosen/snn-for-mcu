== 칩 내부 아날로그 실측 (이 개체 고유값)
================================================================
팩토리 캘리브레이션 값:
  VREFINT_CAL @0x1FF0F44A = 1492  (3.3V, 30'C 에서 측정된 VREFINT ADC 코드)
  TS_CAL1     @0x1FF0F44C = 942  (30'C)
  TS_CAL2     @0x1FF0F44E = 1195  (110'C)

VREFINT 측정 코드 = 1486 (12비트, 64회 평균)
→ VDDA = 3.313 V   ; 이 보드에 지금 실제로 걸린 아날로그 공급 전압

온도센서 측정 코드 = 968 (12비트, 64회 평균)
→ 다이 온도 = 39.16 'C  (VDDA 보정 후 코드 971)
   공식: T = 80/(TS_CAL2-TS_CAL1) * (TS_DATA*VDDA/3.3 - TS_CAL1) + 30

VBAT 측정 코드 = 1021 → VBAT = 3.303 V (내부 1/4 분압 보정 후)
   주: 이 보드에 백업 배터리가 없으면 VBAT은 VDD에 묶여 있다.

== 저속 발진기 실측 (LSI / LSE)
================================================================
LSI: LSIRDY=1
→ LSI 실측 = 26616 Hz  (공칭 32000 Hz, TIM5 타이머클럭 100000000 Hz 기준)
   공칭 대비 편차 -16.8 %  ; RC 발진기라 개체·온도별로 크게 흔들린다

LSE: 시도 전 LSEON=1, 기동 후 LSERDY=1 (BDCR=0x00000003)
→ LSE 실측 = 32765 Hz (공칭 32768 Hz) ; 32.768kHz 크리스탈이 실장되어 있다

HSE: 현재 HSEON=1 HSERDY=1 HSEBYP=0
   HSEBYP=0 이면 크리스탈 발진 모드, 1이면 외부 클럭 입력 모드다.
   주: SYSCLK이 HSE 기반 PLL로 돌고 있으므로 HSE를 껐다 켜는 실험은 하지 않는다.

== I2C 버스 스캔 (보드에 실장된 칩 실측)
================================================================
각 주소에 START+주소를 보내고 ACK가 돌아오는지로 판정한다.
주소는 7비트/8비트 표기를 함께 적는다 (8비트 = 7비트 << 1).

--- I2C3 (PH7=SCL, PH8=SDA, AF4 — 오디오 코덱·터치 컨트롤러 계열) ---
  응답: 7비트 0x1A (8비트 0x34)  → WM8994 오디오 코덱 (AUDIO_I2C_ADDRESS)
  응답: 7비트 0x38 (8비트 0x70)  → FT5336 정전식 터치 컨트롤러 (TS_I2C_ADDRESS)
  총 2개 장치가 응답했다.
  BSP 헤더에 정의된 주소별 응답 여부:
    0x34 응답 WM8994 오디오 코덱 (AUDIO_I2C_ADDRESS)
    0x70 응답 FT5336 정전식 터치 컨트롤러 (TS_I2C_ADDRESS)
    0x60 무응답 카메라 모듈 (CAMERA_I2C_ADDRESS, 보통 미장착)
    0xA0 무응답 EEPROM A01 (EEPROM_I2C_ADDRESS_A01)
    0xA6 무응답 EEPROM A02 (EEPROM_I2C_ADDRESS_A02)

--- I2C1 (PB8=SCL, PB9=SDA, AF4 — Arduino 확장 커넥터) ---
  응답한 장치 없음.
  BSP 헤더에 정의된 주소별 응답 여부:
    0x34 무응답 WM8994 오디오 코덱 (AUDIO_I2C_ADDRESS)
    0x70 무응답 FT5336 정전식 터치 컨트롤러 (TS_I2C_ADDRESS)
    0x60 무응답 카메라 모듈 (CAMERA_I2C_ADDRESS, 보통 미장착)
    0xA0 무응답 EEPROM A01 (EEPROM_I2C_ADDRESS_A01)
    0xA6 무응답 EEPROM A02 (EEPROM_I2C_ADDRESS_A02)

터치 컨트롤러 식별 (I2C3 0x70):
  reg 0xA8 = 0x51   ; 칩 ID (FT5336_CHIP_ID_REG) — FT5336이면 0x51
  reg 0xA6 = 0x12   ; 펌웨어 버전 (FT5336_FIRMID_REG)
  reg 0xA3 = 0x6F   ; 패널 ID
  reg 0xAF = 0xEA   ; 릴리스 코드
  reg 0xA1 = 0x99   ; 라이브러리 버전 하위 바이트
  → 칩 ID가 0x51이므로 이 보드의 터치 컨트롤러는 FT5336으로 확정된다.

== 보드 주변 부품 실측 (ID 레지스터·핀 상태)
================================================================

오디오 코덱 식별 (I2C3 0x34):
  reg 0x0000 (칩 ID) = 0x8994
  → 0x8994이므로 오디오 코덱은 WM8994로 확정된다.

이더넷 PHY 식별 (MDIO: PA2=MDIO, PC1=MDC):
  PHY 주소 0: ID1=0x0007 ID2=0xC131
      OUI=0x0001F0  모델=0x13  리비전=0x1
      → SMSC/Microchip LAN8742A 계열로 식별된다.
      BMCR=0x3000 BMSR=0x7809  링크=down, 자동협상=미완료

보드 입력 핀 상태:
  PC13 (SD_DETECT) = 0  → microSD 카드 삽입됨
  PI11 (사용자 버튼 B1) = 0  → 눌리지 않음
  PI1  (LED1/LD1) 은 이 펌웨어가 진행 표시용으로 출력 구동 중
  PI12 (LCD_DISP), PK3 (LCD 백라이트) 는 LCD를 초기화하지 않아 건드리지 않았다

LTDC (LCD-TFT 컨트롤러) 현재 레지스터:
  SSCR=0x00000000 BPCR=0x00000000 AWCR=0x00000000 TWCR=0x00000000 GCR=0x00000000
  → 타이밍 레지스터가 비어 있다. 이 펌웨어는 LCD를 초기화하지 않는다.

== 메모리 서브시스템 실측
================================================================
SYSCLK 200000000 Hz 기준. 반복 3회의 최솟값을 쓴다 (최솟값이 노이즈가 가장 적다).
측정 하네스 오버헤드 29 cyc (함수 포인터 호출 + dsb/isb). 모든 수치에서 이미 뺐다.
측정 중 인터럽트는 PRIMASK로 차단한다. 폴트 복구용 벡터테이블을 0x20001000에 임시 설치했다.
버퍼 배치: ITCM 0x00001940(4 KB) DTCM 0x20001200(32 KB) SRAM1 0x20016C60(64 KB) SRAM2 0x2004C000(8 KB)
외부/백업 메모리 실측 판정: SDRAM=사용 가능  QSPI=사용 가능  BKPSRAM=사용 가능

== 1. 메모리 영역 실제 크기 실측 (aliasing / 폴트 경계 탐색)
================================================================
방법: 기준 주소에 표식을 쓰고 2^k 오프셋마다 다른 값을 써 본 뒤 기준을 다시 읽는다.
      기준값이 바뀌면 되감김(WRAP), 쓴 값이 유지되지 않으면 없는 메모리(DEAD),
      버스 폴트면 FAULT. 첫 실패 지점은 1KB 단위 이분 탐색으로 좁혔다.
      읽기 전용 영역(FLASH/QSPI)은 쓰기 시험이 불가하므로 '읽어서 폴트가 나는
      첫 주소'만으로 상한을 잡는다 (되감김은 이 방법으로 구분되지 않는다).
      D-cache는 이 시험 동안 OFF다 (캐시가 되감김을 가려 버린다).

region       base        DS크기     실측크기   판정   경계에서
---------------------------------------------------------------
ITCM         0x00001940     16 KB     16 KB  FAULT +0x00002800 에서 FAULT  [일치]
DTCM         0x20001200     64 KB    320 KB  FAULT +0x0004F000 에서 FAULT  [불일치]
SRAM1        0x20016C60    240 KB    256 KB  FAULT +0x00039400 에서 FAULT  [불일치]
SRAM2        0x2004C000     16 KB     16 KB  FAULT +0x00004000 에서 FAULT  [일치]
BKPSRAM      0x40024000      4 KB      4 KB  FAULT +0x00001000 에서 FAULT  [일치]
SDRAM        0xC0000000   8192 KB   8192 KB  FAULT +0x00800000 에서 FAULT  [일치]
FLASH_AXIM   0x08000000   1024 KB   1024 KB  FAULT +0x00100000 에서 FAULT  [일치]
FLASH_ITCM   0x00200000   1024 KB   1024 KB  FAULT +0x00100000 에서 FAULT  [일치]
QSPI         0x90000000  16384 KB  16384 KB  FAULT +0x01000000 에서 FAULT  [일치]

주의: DTCM(0x20000000+64K) - SRAM1(0x20010000) - SRAM2(0x2004C000)은 주소가 연속이라
      쓰기 시험만으로는 서로의 경계가 드러나지 않는다 (되감김이 없다). 각 영역의 실측값은
      '그 주소에서 위로 얼마나 더 실재하는 메모리가 이어지는가'로 읽어야 하며,
      물리적 경계는 아래 2번의 접근 지연 스캔이 갈라 준다.

== 2. 접근 지연으로 본 물리 경계 (주소가 연속인 영역 구분)
================================================================
같은 주소 공간이라도 물리적으로 다른 메모리면 접근 비용이 다르다.
아래는 D-cache OFF 상태에서 32B 간격 읽기의 접근당 사이클이다 (루프 오버헤드 포함).

[0x20000000 대역] 4 KB 간격 접근 지연 스캔 (D-cache OFF, 32B 스트라이드 읽기)
  0x20000000 - 0x2000FFFF :   5.16 cyc/접근
  0x20010000 - 0x2004FFFF :  15.66 cyc/접근
  0x20050000 - 0x20053FFF : 접근 불가 (버스 폴트)

[0x00000000 대역] 1 KB 간격 접근 지연 스캔 (D-cache OFF, 32B 스트라이드 읽기)
  0x00000000 - 0x00003FFF :   5.16 cyc/접근
  0x00004000 - 0x00005FFF : 접근 불가 (버스 폴트)

참고: 스트라이드 루프 자체의 오버헤드는 2.00 cyc/회 다 (위 값에 포함되어 있다).

ART(ARTEN+PRFTEN)는 ITCM 경로의 명령/데이터 페치를 가속하는 장치다. AXIM 경로는
ART가 아니라 D-cache와 프리페치 큐가 담당한다. 위 표에서 각 경로가 무엇에 반응하는지
직접 읽어낼 수 있다.
